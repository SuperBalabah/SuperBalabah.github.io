# SuperBalabah — Interactive Polymath Portfolio

A modern, high-craft personal portfolio built for **SuperBalabah** (NTU Medical Student, Self-Taught Software Developer, Musician & Audio Engineer, MMA & Outdoor Enthusiast).

Designed with a **Brittany Chiang Two-Column Split Layout**, **Mouse Spotlight Cursor Glow**, and **Japanese Minimalist (Wabi-Sabi Charcoal Matte) & Quiet Luxury** aesthetic.

### 🚀 Key Features & UI Design

1. **Brittany Chiang Indicator Line Navigation**:
   - Left-sidebar fixed menu (`—— ABOUT`, `—— PROJECTS & CODE`, `—— PUBLIC HEALTH & RESEARCH`, `—— MUSIC & AUDIO`) with dynamic line expansion (`—————`) and teal highlights on scroll/hover.
   - Minimalist SVG social icons at bottom-left with tooltips.

2. **Cursor Spotlight Glow**:
   - Ambient radial gradient follower (`MouseSpotlight.tsx`) tracking mouse coordinates across the screen.

3. **Japanese Minimalist & Quiet Luxury Aesthetic**:
   - Matte Wabi-Sabi Charcoal background (`#0d0f12`), dark slate cards (`#14171d`), generous Yohaku (和紙留白), zero emoji noise.
   - Japanese Bamboo Teal (`#14b8a6`) and Quiet Luxury Gold (`#b89f74`) accents.

4. **Multi-Domain Showcase**:
   - **Public Health & Clinical Tools**: Interactive preeclampsia risk reports, sleep hygiene calculators.
   - **Code & Systems**: PWA news radar, quantitative trading strategy dashboards, JSON report generators.
   - **Original Music & Vocal Covers**: Integrated audio player supporting custom song previews.

### 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom CSS Variables + Framer Motion
- **Icons**: Lucide React
- **Deployment**: GitHub Pages (`https://SuperBalabah.github.io`)

### 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/SuperBalabah/SuperBalabah.github.io.git
cd SuperBalabah.github.io

# Install dependencies
npm install

# Run dev server
npm run dev

# Build production bundle
npm run build
```
